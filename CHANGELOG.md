# Changelog

## 0.1.0-rc.1

First GitHub release candidate for OpenCode V2 >=2.0.15, <3 on macOS/Linux.

- Native ESM package with Git-package and local-directory installation.
- Lazy, locked Python 3.12 runtime, serialized setup and interruption recovery.
- Explicit private/shared initialization and identity-preserving installer adoption.
- Independent source, literature-note and general-reference corpora.
- Committed-upstream snapshots, atomic generation publication, embedding reuse,
  source anchors, policy provenance and separate integrity/currency reporting.
- Shared compatible daemon/model cache across connections and worktrees.
- Advisory corpus setup inspection and query-readiness/indexing progress.
- Linux/macOS installed-artifact integration and verified source/npm bundles.

Literature-note search provides discovery evidence from committed notes. Full-text
ingestion and automatic cache/generation garbage collection remain later extensions.
The npm registry distribution follows candidate validation.
